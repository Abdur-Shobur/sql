What Can do ADD?

ADD can do 5 things

1. A new column add
2. A Primary Key add
3. A Foreign Key add
4. A Constraint add
5. An Index Add

```sql
-- ADD COLUMN
ALTER TABLE my_table 
	ADD COLUMN name CHAR(255)

-- ADD MULTIPLE COULUMN
ALTER TABLE my_table
	ADD COLUMN (
						gender CHAR(1),
						hire_date DATE					
			)

-- ADD PRIMARY KEY
ALTER TABLE my_table 
	ADD PRIMARY KEY (email)

-- ADD FOREIGN KEY
ALTER TABLE my_table
	ADD FOREIGN KEY (customer_id)
	REFERENCES customers(id)

-- ADD INDEX
ALTER TABLE my_table
	ADD INDEX idx_name(name)

-- ADD UNIQUE Constaiant
	ALTER TABLE my_table
		ADD UNIQUE (email)
```
