 The AS keyword in SQL is used to give a temporary alias (or nickname) to a table or a column.

1. Creating an Alias for a Column
 ```sql
SELECT column_name AS alias_name
FROM table_name;

SELECT FirstName || ' ' || LastName AS FullName
FROM Employees;

 ```

2 Using AS to Rename a Table
 ```sql
SELECT E.FirstName, E.LastName, D.DepartmentName
FROM Employees AS E
JOIN Departments AS D ON E.DepartmentID = D.DepartmentID;
 ```

3. Alias for Expressions or Calculations
 ```sql
SELECT FirstName, LastName, Salary, (Salary * 1.10) AS SalaryWithBonus
FROM Employees;
 ```

 4. Using AS with a Table Alias in a Join
 ```sql
SELECT A.EmployeeID, A.FirstName, B.DepartmentName
FROM Employees AS A
JOIN Departments AS B ON A.DepartmentID = B.DepartmentID;
 ```

5. Using AS for Multiple Columns in a Query
 ```sql
SELECT FirstName AS "Employee First Name", 
       LastName AS "Employee Last Name", 
       Salary * 1.10 AS "Salary After Bonus"
FROM Employees;
 ```
