It is a constraint that ensures the data meets certain conditions or criteria, helping to ensure the correctness and consistency of the data

1. Column-Level CHECK Constraint:
```sql
CREATE TABLE table_name (
    column_name data_type,
    CONSTRAINT constraint_name CHECK (condition)
);

```
2. Table-Level CHECK Constraint:
```sql
CREATE TABLE table_name (
    column1 data_type,
    column2 data_type,
    CONSTRAINT constraint_name CHECK (condition)
);
```
3. Using CHECK with Multiple Columns:
```sql
CREATE TABLE Projects (
    ProjectID INT PRIMARY KEY,
    ProjectName VARCHAR(255),
    StartDate DATE,
    EndDate DATE,
    CONSTRAINT chk_EndDate CHECK (EndDate > StartDate)
);
```
4. Using CHECK with Enum-like Values:
```sql
CREATE TABLE Employees (
    EmployeeID INT PRIMARY KEY,
    Name VARCHAR(100),
    Gender CHAR(1),
    CONSTRAINT chk_Gender CHECK (Gender IN ('M', 'F'))
);
```
Adding a CHECK constraint to an existing table:
```sql
CREATE TABLE Employees (
    EmployeeID INT PRIMARY KEY,
    Name VARCHAR(100),
    Gender CHAR(1),
    CONSTRAINT chk_Gender CHECK (Gender IN ('M', 'F'))
);
```
